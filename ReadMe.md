# 💸 Interactive Financial Flow Sankey Builder

A lightweight, highly customizable personal finance dashboard built with **Python**, **Streamlit**, and **Plotly**. This application allows you to visualize your income and expense pipelines using interactive Sankey diagrams, track spending across custom categories and months, and export your data easily.

## ✨ Features
- **Dynamic Flow Builder:** Easily add custom sources and targets (such as salary splits, monthly breakdowns, or specific accounts like an NRE account).
- **Live Visual Pipeline:** Watch your financial Sankey diagram update instantly with vibrant, color-coded streams.
- **Embedded Values:** Category nodes automatically calculate and display their total amounts directly on the chart blocks.
- **Easy Branch Management:** Select and delete individual flows or reset your data cleanly at any time.
- **CSV & Image Export:** Download your complete financial structure as a CSV spreadsheet or capture a high-resolution snapshot of your diagram.
